# Awesome Office AI Copilots — design notes

## Scope

This repository is an independent, bilingual directory of global Office AI copilots and adjacent productivity agents. It is intentionally useful without requiring an account or JavaScript: the README is the canonical list, while GitHub Pages adds search and filters.

## Source policy

- Use official product pages as the primary source.
- Keep descriptions short and capability-focused.
- Avoid prices unless they are explicitly verified and likely to remain stable.
- Record uncertainty rather than turning a beta, regional rollout, or add-in into a universal claim.

## Pages deployment

The workflow publishes `docs/` through GitHub Pages. If the site uses a custom domain later, add a sitemap with the final GitHub Pages URL and update any repository links.
